## 阶段 1：注册账号（每步约 5-15 分钟）

### 1.1 GitHub（数据仓库 + 定时任务）

- [ ] 打开 https://github.com → Sign up 注册（邮箱+密码+验证）
- [ ] 登录后，右上角 `+` → New repository
- [ ] Repository name 填 `aidash` → 选 Public → Create repository
- [ ] 仓库 Settings → Pages → Source 选 "Deploy from a branch" → main / (root) → Save
- [ ] 记下 Pages 地址：`https://jiejinfeilu.github.io/aidash/web/`
- [ ] 建写入 Token：右上角头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
- [ ] 勾选 Only select repositories → 选 aidash → Contents 选 Read and write → 过期 90 天 → Generate → **立即复制保存**（只显示一次）
- [ ] 开 Actions 写权限：仓库 Settings → Actions → General → Workflow permissions → Read and write → Save

### 1.2 Vercel（后端）

- [ ] 打开 https://vercel.com → Sign Up → 用 GitHub 登录
- [ ] Add New → Project → Import 你的 `aidash` 仓库
- [ ] Framework Preset 选 Other；Build Command / Output 留空
- [ ] 先不配环境变量，Deploy 一次看是否成功（报错也正常，下一步补）

### 1.3 DeepSeek（AI）

- [ ] 打开 https://platform.deepseek.com 注册登录
- [ ] 左侧 API Keys → 创建 API Key → **立即复制保存**
- [ ] 左侧充值 → 充 ¥10~50

### 1.4 QQ 邮箱 SMTP（发 Kindle 推送）

- [ ] 网页版 mail.qq.com 登录 → 设置 → 账户
- [ ] 找到 "POP3/IMAP/SMTP 服务" → 开启 → 按提示发短信
- [ ] 得到 16 位**授权码** → **立即复制保存**（不是登录密码！）

### 1.5 Kindle（接收推送）

- [ ] 确认 Kindle 是国际账户（amazon.com）；不是的话先按 G 文档切换
- [ ] 电脑打开 amazon.com → 管理我的内容和设备 → 首选项 → 个人文档设置
- [ ] 记下 `xxx@kindle.com` 邮箱
- [ ] 把发件 QQ 邮箱加进"已批准的个人文档电子邮件列表"
- [ ] Kindle 上：设置 → 设备选项 → 高级选项 → 打开"显示封面"

## 阶段 4：Vercel 配置环境变量并部署（约 10 分钟）

- [ ] Vercel 项目 → Settings → Environment Variables，添加 9 个：
  - `AI_PROVIDER` = `deepseek`
  - `DEEPSEEK_API_KEY` = 阶段 1.3 复制的 Key
  - `DEEPSEEK_MODEL` = `deepseek-chat`
  - `OPENAI_API_KEY` = （留空）
  - `OPENAI_MODEL` = `gpt-4o-mini`
  - `GITHUB_TOKEN` = 阶段 1.1 复制的 Token
  - `GITHUB_REPO` = `你的用户名/aidash`
  - `GITHUB_BRANCH` = `main`
  - `APP_PIN` = 你自己定 4~6 位口令（如 `8866`，别用 1234）
- [ ] 回到 Deployments 标签 → 重新 Deploy（或仓库有更新会自动部署）
- [ ] 记下部署地址：`https://aidash-xxxxx.vercel.app`

**验证**：电脑浏览器打开 `https://aidash-xxxxx.vercel.app/api/process`，应该看到 405 或 401 提示（说明接口活着）。

## 阶段 6：配置 GitHub Actions 定时任务（约 10 分钟）

- [ ] 仓库 Settings → Secrets and variables → Actions → New repository secret，添加 6 个：
  - `SMTP_HOST` = `smtp.qq.com`
  - `SMTP_PORT` = `465`
  - `SMTP_USER` = 你的 QQ 邮箱
  - `SMTP_AUTH_CODE` = 阶段 1.4 的授权码
  - `SMTP_FROM` = `AiDash`
  - `KINDLE_EMAIL` = 阶段 1.5 的 `xxx@kindle.com`
- [ ] 仓库 Actions 标签 → 左侧 "Fetch Hotlists" → Run workflow → 等绿勾
- [ ] 左侧 "Daily Kindle Push" → Run workflow → 等绿勾
- [ ] 检查仓库出现 `feeds.json`；邮箱收到 EPUB 附件

## 卡点速查（做不动时先看这里）

| 卡在哪 | 大概率原因 | 怎么做 |
|---|---|---|
| GitHub 上传后页面打不开 | Pages 还没更新 / 用户名错 | 等 1-3 分钟；检查仓库名和用户名拼写 |
| Vercel 部署报错 | 环境变量没配 / 代码没传全 | 检查 api/ 和 vercel.json 是否在仓库 |
| 手机提示 401 | 口令不一致 | 手机设置的口令 = Vercel 的 APP_PIN |
| AI 处理失败 502 | Key 没配 / 没充值 / 模型名错 | 检查 DEEPSEEK_API_KEY、余额 |
| 保存失败 502 | Token 权限不够 | 重发 Token，Contents 必须 Read and write |
| Actions 发信失败 | Secrets 没配 / 授权码错 | 检查 6 个 Secrets；授权码不是登录密码 |
| Kindle 收不到 | 白名单没加 / 国区邮箱 | 加发件邮箱到白名单；确认 @kindle.com |
| 锁屏不是仪表盘 | 没打开那本书 / 广告版 | 打开书再休眠；广告版需移除特惠 |

> 任何一步卡住，把**屏幕截图 + 报错文字**发给 Codex，我带你排查。
