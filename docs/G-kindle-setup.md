# AiDash — G 部分：Kindle 端操作说明

目标：让 Kindle 休眠（锁屏）时显示全屏仪表盘封面。

原理：Kindle 的“显示封面”功能会在休眠时显示**你当前打开的那本书**的封面。
所以我们要做的只有三件事：① 让 Kindle 能收到邮件推送；② 开启“显示封面”；
③ 每天收到书后打开一次，然后锁屏。

---

## 1. 确认 Kindle 用的是国际账户（最重要）

**`@kindle.cn` 邮箱已于 2024 年停用**，国区账户收不到任何邮件推送。
必须使用国际账户（amazon.com）的 `@kindle.com` 邮箱。

### 怎么看自己是不是国际账户

- Kindle 上：设置 → 我的账户 → 查看登录邮箱，是 `@amazon.com` / `@amazon.co.jp` 等国际账号，而不是 `@amazon.cn`。
- 电脑上打开 amazon.com，能正常登录，且能看到你的 Kindle 设备。

### 如果还是国区账户，切换方法

1. Kindle 设置 → 我的账户 → **注销设备**（登出）。
2. 用浏览器打开 https://www.amazon.com 注册一个国际账户
   （大陆手机号/邮箱都能注册；支付方式可以先不填）。
3. Kindle 设置 → 我的账户 → 用国际账户重新登录注册。
4. 注册后稍等，登录 amazon.com → 管理我的内容和设备 → 设备，
   确认能看到你的 Kindle。

> 提示：如果注册时提示所在国家不支持，把账户地址改成美国或日本等
> 支持 Kindle 的国家即可（地址可填任意有效地址）。

---

## 2. 获取你的 `@kindle.com` 邮箱

1. 电脑打开 https://www.amazon.com 登录国际账户。
2. 顶部“账户与列表” → **管理我的内容和设备**（Manage Your Content and Devices）。
3. 切到 **首选项**（Preferences）标签 → 找到 **个人文档设置**（Personal Document Settings）。
4. 里面会显示“发送至 Kindle”邮箱，形如 `你的名字_数字@kindle.com`。
   这个就是 `KINDLE_EMAIL`，要填到 `scripts/config_local.py` 或 GitHub Actions Secrets。

---

## 3. 把发件邮箱加入白名单

同一个页面（个人文档设置）往下滚，找到
**已批准的个人文档电子邮件列表**（Approved Personal Document E-mail List）。

- 把你的发件邮箱（如 `xxx@qq.com`）加进去。
- **不加会被直接拒收**，邮件不会出现在 Kindle 上。

---

## 4. 开启“显示封面”

Kindle 上操作：

1. 设置（齿轮图标）→ **设备选项** → **高级选项**。
2. 找到 **显示封面**（Show Cover），打开。
3. 如果找不到这个选项，先升级固件（设置 → 设备选项 → 高级选项 → 更新您的 Kindle）。

---

## 5. 接收推送并锁屏显示仪表盘

1. Kindle 连上 Wi-Fi（设置 → Wi-Fi 与蓝牙）。
2. 每天推送后（默认 07:30 后几分钟），主页会多一本
   “AiDash 每日仪表盘 日期” 的书。
3. **点开这本书一次**（翻到封面页即可），然后按电源键休眠。
4. 锁屏就会显示全屏仪表盘封面。

> 重要：Kindle 显示的是“当前打开的书”的封面。
> 如果之后打开了别的书，锁屏就显示别的封面。
> 所以每天推送后，打开最新那本一次即可。

---

## 6. 常见问题

### 收不到推送

- Kindle 确认连了 Wi-Fi；可到设置 → 同步我的 Kindle 手动触发一次。
- 发件邮箱必须加进“已批准的个人文档电子邮件列表”。
- 推送用的是国际账户 `@kindle.com`；国区 `@kindle.cn` 已停用。
- 邮件发出去后一般 1~10 分钟内到达，耐心等一下。
- 网页版备选：打开 https://www.amazon.com/sendtokindle 直接上传
  `aidash_日期.epub` 手动推送。

### 休眠显示广告而不是封面

你的 Kindle 是“带特惠版”（With Special Offers，俗称广告版）。
需要到 amazon.com → 管理我的内容和设备 → 设备 → 你的 Kindle →
**移除特惠/广告**（可能需要小额付费，有的地区可联系客服免费移除）。

### 休眠显示黑屏或空白

- 确认“显示封面”已开启。
- 确认当前打开的是今天推送的这本书，然后按电源键。
- 如果书还没下载完（主页显示“下载中”），等下载完成再打开。

### 封面是模糊的 / 颜色不对

Kindle 是黑白电子墨水屏，任何图片都会显示为灰阶，这是正常的。
我们的仪表盘本身就是白底黑字，显示效果最好；图片分辨率 1072×1448
正好匹配 Paperwhite 6 的屏幕。

### 邮件提示“无法转换此文件”

确认发送的是 `.epub` 而不是 `.mobi`。2022 年 8 月起亚马逊邮件推送
不再接受 `.mobi`；我们的脚本默认发 EPUB，会自动转换并保留封面。

### 想用数据线直接拷进去

1. 本机运行 `python scripts/send_to_kindle.py --no-send` 生成 EPUB。
2. 把 `scripts/output/` 里的 `.epub` 用数据线拷到 Kindle 的“documents”文件夹。
3. 在 Kindle 上弹出设备后，书会出现在主页。

---

## 7. 一次设置，长期生效

以上 1~4 步只需要做一次。之后每天：

- GitHub Actions 07:30 自动推送；
- Kindle 收到书后，点开一次 → 锁屏，就完成当天“屏保”更新。
